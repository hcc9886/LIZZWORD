# LIZZWORD 商业化方案（免费 / 付费分层与定价）

> 版本：2026-11-21
> 适用：把 LIZZWORD 做成软件（Web + iOS/Android 壳）的阶段
> 前置事实：现在是纯静态站 + Supabase（公开 url + publishable key），26 本书、21,511 条 22 键深度词条，无支付、无权益表。

---

## 0. 一句话建议

**免费给「完整学完 3 本书」的体验，付费卖「全部词书 + 计划 + 跨端 + 发音评分」。**
首年目标不是靠订阅赚钱，而是把「每日打开」做成习惯；定价用 ¥12/月 起测，年付 ¥98 做主力。

## 1. 免费与付费怎么切

切分原则：**免费层必须能完整闭环（学完一本书、复习、看词卡、听发音），付费层卖「广度、效率、陪伴」。**

| 能力 | 免费 | Plus（订阅） | Pro（买断） |
|---|---|---|---|
| 基础 6 本（小学/初中/日常/四级/托福/雅思试用） | ✅ 完整 | ✅ | ✅ |
| IELTS / TOEFL 全量 | 每本试读 50 词 | ✅ | ✅ |
| 17 本考试书（考研/专升本/自考/PETS/FCE/BEC/医护/法律/PTE/留学/英专/新概念/COCA/KET-PET/中高职/AB/自学考试） | ❌ 每本试读 30 词 | ✅ | ✅ |
| 3 本配套书（零基础/词根词缀/高频搭配） | 零基础 ✅ 全量 | ✅ | ✅ |
| 每日新词上限 | 50 | 100 | 100 |
| SRS 复习 / 拼写 / 听力 | ✅ | ✅ | ✅ |
| 学习计划 + 入门问卷 + 每日任务卡 | 基础版 | ✅ 完整 | ✅ |
| 错词本 / 每周复盘 | ✅ | ✅ | ✅ |
| 跟读评分 / 造句批改 | ❌ | 每月 100 次 | 不限 |
| 跨设备同步 / 云备份 | ❌ | ✅ | ✅ |
| 离线整书包 | ❌ | ✅ | ✅ |
| 语音包（自然音库/多口音） | 系统默认 | ✅ 增强 | ✅ 增强 |

> 为什么把「零基础」全免费：拉新最猛，且它是口碑入口；付费转化靠「学完基础后想考雅思/考研」。

## 2. 定价（建议先小规模 A/B）

| 方案 | 价格 | 定位 | 备注 |
|---|---|---|---|
| 月付 | ¥12 / ¥18 两档测试 | 尝鲜 | 先投 ¥12，看转化率；ARPU 低但门槛低 |
| 季付 | ¥30 | 备考周期 | 相当于 ¥10/月 |
| 年付 | ¥98（早鸟 ¥68） | **主力** | 相当于 ¥8.2/月，最适合学生 |
| 买断 | ¥198（早鸟 ¥128） | 厌恶订阅的人 | 只含当前全部词书，后续新书 1 年内免费 |
| 学生认证 | 年付 5 折 | 校园渠道 | 学信网/校园邮箱；人工抽检防滥用 |

**首月 ¥1 试用 7 天**（Stripe 支持，国内支付需签约后做），到期自动转 ¥12；取消入口必须显眼。

**不建议**：一次性卖「终身全解锁 ¥998」——词书还会持续增长，会把未来收入提前透支。

## 3. 怎么吸引消费者（转化设计）

1. **先给结果，再给墙**：新用户不注册也能学完零基础 300 词和初中核心，第 7 天再弹「你已学 120 词，继续学雅思需要 Plus」。
2. **进度可视化**：免费用户首页显示「已掌握 320 词 / 目标 6000」，缺口本身就是付费动机。
3. **考试倒计时**：填考试日期 → 免费版提示「按每天 20 词，你需要 300 天；Plus 不限量可缩到 90 天」。这是最硬的付费理由。
4. **试读最后 30 词**：每本书免费试读 30 词，第 31 词弹一次付费墙（不重复弹）。
5. **限时体验**：每周送 1 天 Plus（周五），养成依赖。
6. **分享裂变**：学习报告分享图带邀请码，双方各得 7 天 Plus。
7. **校园代理**：班级/社团团购 5 折，B 端可做教师端（布置词书、看班级进度）。

## 4. 技术落地（按依赖顺序）

### 4.1 数据模型（Supabase）

```sql
create table profiles (
  id uuid primary key references auth.users,
  plan text not null default 'free',        -- free | plus | pro
  plan_expires_at timestamptz,
  source text,                              -- ios | android | web | promo
  student_verified boolean default false,
  created_at timestamptz default now()
);

create table purchases (
  id uuid primary key default gen_random_uuid(),
  user_id uuid references auth.users,
  provider text,                            -- stripe | apple | google | wechat | alipay
  provider_ref text,
  amount_cents int,
  currency text,
  status text,                              -- paid | refunded | failed
  created_at timestamptz default now()
);
```

RLS：用户只能读自己的 `profiles` / `purchases`；`plan` 只能由服务端（Edge Function / webhook）写。

### 4.2 权益校验

- 前端只读 `profiles.plan` 决定展示，**不信任本地存储**。
- 付费词书分片不放公开目录，放 Supabase Storage 私有桶，用短时签名 URL 下发；免费书继续静态托管。
- 静态站被扒源码也没关系：核心 6 本本来就是获客成本。

### 4.3 支付渠道

| 渠道 | 适用 | 要点 |
|---|---|---|
| Stripe | 海外 Web | Checkout + webhook 校验签名 |
| Apple IAP | iOS App | 必须走 IAP，不能跳外部支付；订阅组配置 |
| Google Play Billing | Android | 同上 |
| 微信/支付宝 | 国内 Web/小程序 | 需商户号、备案、回调验签；自动续费需显著提示 |

### 4.4 客户端门锁

- 新增 `books/lizz/entitlements.js`：单一配置源（免费书 id、试读词数、每日额度），前端只读它。
- 打开受保护书时：第 N 词后插入 paywall 卡片 → 引导登录 → 校验 `plan`。
- 所有付费判定集中在 `canUse(feature)` 一个函数，方便以后改规则。

## 5. 避免踩坑

1. **合规**：大陆支付需主体资质 + ICP 备案；自动续费必须提前显著提示、可随时取消；未成年人需监护人同意。
2. **退款**：7 天无理由，App Store 走苹果退款流程，别自己硬拦。
3. **别在 JSON 里写价格**：价格只放配置/服务端，改价不用重发词书。
4. **别做「付费才能看释义」**：会劝退；付费墙放在「词书广度 + 计划 + 同步 + 评分」。
5. **免费额度别太低**：每日 20 新词是底线，低于 15 会被骂。
